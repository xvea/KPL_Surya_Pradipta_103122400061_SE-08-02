### Event Delegation dalam JavaScript
Event Delegation adalah teknik menangani event dengan memasang satu event listener pada elemen parent, lalu membiarkan elemen tersebut menangani event dari elemen child. Teknik ini memanfaatkan konsep event bubbling, yaitu ketika suatu event terjadi pada elemen, event tersebut akan naik ke parent hingga ke document.

Sebagai contoh, jika sebuah daftar memiliki banyak tombol hapus, kita tidak perlu memasang `addEventListener()` pada setiap tombol. Cukup pasang satu listener pada elemen daftar, lalu gunakan `event.target` untuk mengetahui tombol mana yang diklik.

```js
document.getElementById("list").addEventListener("click", (event) => {
  if (event.target.classList.contains("delete")) {
    console.log("Tombol hapus diklik");
  }
});
```

Keuntungan utama Event Delegation adalah lebih hemat memori, meningkatkan performa, dan mendukung elemen yang ditambahkan secara dinamis tanpa perlu memasang listener baru. Karena itu, teknik ini sering digunakan pada aplikasi web modern yang memiliki banyak elemen interaktif seperti daftar tugas, tabel data, menu navigasi, dan sistem komentar.

Dalam perspektif design pattern, Event Delegation memiliki kemiripan dengan Mediator Pattern, karena elemen parent bertindak sebagai perantara yang menerima dan mengatur event dari banyak elemen anak. Dengan demikian, kode menjadi lebih sederhana, mudah dirawat, dan lebih efisien dibandingkan memasang listener pada setiap elemen secara langsung.
