## Tugas

Dari dua kode di bawah ini, mana yang kamu ingin cari masalahnya dan perbaiki di tengah-tengah malam, katakanlah jam 1 malam? Mengapa?

```js
function processUser(user) {
  if (user) {
    if (user.isActive) {
      if (user.hasPermission) {
        return doSomething(user)
      }
    }
  }
  return null
}
```

```js
function processUser(user) {
  if (!isValidCandidate(user)) return null;
  return doSomething(user);
}

function isValidCandidate(user) {
  return user && user.isActive && user.hasPermission;
}
```

## Jawaban

Jika harus mencari dan memperbaiki masalah pada pukul 1 malam, maka akan lebih memilih kode kedua.

```js
function processUser(user) {
  if (!isValidCandidate(user)) return null;
  return doSomething(user);
}

function isValidCandidate(user) {
  return user && user.isActive && user.hasPermission;
}
```

Alasannya karena kode tersebut lebih mudah dibaca dan tujuan dari kode langsung terlihat. Ketika melihat `if (!isValidCandidate(user)) return null;`, mudah memahami bahwa ada proses validasi pengguna sebelum menjalankan `doSomething(user)`. Sebaliknya, pada kode pertama ada beberapa tingkat `if` yang bersarang untuk memahami kondisi yang diperlukan agar fungsi dapat dijalankan.

Selain itu, kode kedua memiliki beban mental yang lebih rendah saat proses debugging. Logika validasi dipisahkan ke dalam fungsi `isValidCandidate()`, sehingga aturan-aturan yang menentukan apakah pengguna valid atau tidak berada di satu tempat. Jika terjadi masalah, dapat langsung memeriksa fungsi tersebut tanpa harus menelusuri beberapa blok kondisi yang bertingkat. Pemisahan ini juga membuat kode lebih mudah diuji dan dipelihara.
